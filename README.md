# pyndulum

Python code for doing pendulum stuff.


##Installation 

Clone the repository (if you don't plan to edit it):

git clone git@github.com:jatkinson1000/git-for-science.git

Then install a Python package:

python -m venv pendulum-venv

source pendulum-venv/bin/activate

pip install --editable ./

## Usage

An example:

import pendulum

pyndulum.equations.get_period(2)
